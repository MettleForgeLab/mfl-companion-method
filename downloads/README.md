# Downloads

**Meet_MFL_0.4_Personal_Example.zip** is the fixed teaching example for MFL Companion Method v1.0.0.

It contains the generic message, accepted Edition 02 PDF, accepted Meet MFL edition 0.4 companion, receiving directions, license text, and rights scope.

The ZIP is repository teaching packaging. It does not create a new edition of the PDF, companion, or message. Their accepted identities are recorded in `examples/meet-mfl-0.4/SOURCE_IDENTITIES.json`.

Fixed file identities are listed in the repository `RELEASE_MANIFEST.json` and `SHA256SUMS.txt`.
