# Companion starter

[Read the starter](COMPANION_STARTER.txt).

This is a new drafting aid, not an accepted institutional companion or a tested universal format. Use it to compose an account of a subject you know. Replace the bracketed fields, supply real sources, remove authoring notes, and review the resulting file with the person responsible for the subject.

The prompts are intentionally broad. A small project may need less than one page; a connected institution may need a substantial account and a selective deeper-resource index. Useful preparation comes from the material you choose and how you relate it.
