# Meet MFL: a complete example

The **Friends and Family** introduction demonstrates the three parts without assuming that the recipient wants to hire or fund MFL. It welcomes interest in tools, stories, visual craft, and the person making the work. The professional offer remains visible.

- [Read the personal-message template](01-friends-and-family/MESSAGE.md). Replace the two placeholders before sending.
- [Open the accepted PDF](01-friends-and-family/Meet_MFL_A_Look_Around.pdf).
- [Read the companion on GitHub](01-friends-and-family/Meet%20MFL.txt).
- [Download the raw companion](https://raw.githubusercontent.com/MettleForgeLab/mfl-companion-method/main/examples/meet-mfl-0.4/01-friends-and-family/Meet%20MFL.txt).
- [Get the complete example ZIP](../../downloads/Meet_MFL_0.4_Personal_Example.zip).

The PDF is accepted **Edition 02** and the shared companion is accepted **edition 0.4**. Their content is unchanged. MESSAGE.md contains the unchanged generic personal-message wording supplied by Porter; there is no recipient name or private connection filled in.

This repository preserves the companion's literal stable filename, **Meet MFL.txt**, matching the PDF and receiving directions. That is a packaging choice, not a content revision. SOURCE_IDENTITIES.json records the accepted member identities and the source container observed during preparation.

MFL also has accepted prospective-client, educational-institution, and financial-backer presentations using the same companion. This first repository example shows one complete arrangement; it does not reproduce all four.
